# Factory AI Journal

Factory AI Journal is a simple mobile-first MVP for a personal industrial shift journal.

## Structure

- `backend/` Laravel 12 API backend scaffold
- `frontend/` Next.js TypeScript frontend scaffold

## Current scope

- Project structure
- Environment templates
- Backend health endpoint
- Frontend homepage

## Notes

This workspace does not currently have PHP or Composer installed, so the backend is prepared as a Laravel 12-ready scaffold rather than an installed framework checkout.
